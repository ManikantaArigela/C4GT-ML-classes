# 🤖 C4GT ML Classes

Welcome to **C4GT ML Classes** — a hands-on repository for learning and practicing **Machine Learning with Python**.

This repository contains class notes, Jupyter notebooks, data preprocessing exercises, regression algorithms, and practical machine learning projects developed as part of the C4GT learning journey.

---

## 📌 About the Repository

The main goal of this repository is to build a strong foundation in Machine Learning through:

- 📊 Data preprocessing
- 📈 Linear Regression
- 📉 Multiple Linear Regression
- 🏠 Regression-based projects
- 🐍 Python programming for Machine Learning
- 📓 Hands-on Jupyter Notebook exercises
- 🧠 Practical implementation of ML concepts

The repository will be continuously updated as new concepts and projects are covered.

## 📚 Topics Covered

### 1. Data Preprocessing

The `data-preprocessing.ipynb` notebook focuses on preparing raw data for Machine Learning.

Topics include:

- Loading datasets
- Understanding datasets
- Handling missing values
- Data cleaning
- Feature selection
- Data transformation
- Preparing data for model training

---

### 2. Linear Regression

The `linear-regression.ipynb` notebook demonstrates the fundamentals of **Linear Regression**.

Key concepts:

- Independent and dependent variables
- Best-fit line
- Training a regression model
- Making predictions
- Model evaluation
- Understanding regression results

Basic workflow:

```text
Dataset
   ↓
Data Preprocessing
   ↓
Train/Test Split
   ↓
Linear Regression Model
   ↓
Model Training
   ↓
Prediction
   ↓
Evaluation
```

---

### 3. Multiple Linear Regression

The `multi linear regression` directory contains practical work related to **Multiple Linear Regression**.

Multiple Linear Regression uses multiple independent variables to predict a dependent variable.

Example:

```text
House Size
Bedrooms
Location
Age of House
      ↓
Multiple Linear Regression
      ↓
Predicted House Price
```

---

### 4. House Price Regression Project 🏠

The `house_price_regression_project` directory contains a practical Machine Learning project based on **house price prediction**.

The project demonstrates how Machine Learning concepts can be applied to a real-world prediction problem.

Typical workflow:

```text
Raw Dataset
     ↓
Data Exploration
     ↓
Data Preprocessing
     ↓
Feature Selection
     ↓
Model Training
     ↓
Prediction
     ↓
Model Evaluation
```
